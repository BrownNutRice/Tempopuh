## Highlights

Six appearance presets, OLED and experimental Light/Follow System tones; font/layout/motion controls; Home arrangement, saved looks and appearance-only JSON transfer; optional compact Now Playing with artwork.

## Validation and limitations

Original publication used the beta workflow's unit, lint, APK and emulator gates. Physical-device Light/System contrast, compact layouts, TalkBack, playback and battery validation were still pending. Appearance-only transfer does not contain listening history or credentials.

## Install

Prerelease debug APK for Android 8.0+, package `me.avinas.tempo`. Export a backup before replacing an installation. A matching signing certificate is required for an in-place update; provider OAuth configuration must match the installed signer.
