## Highlights

## Validation and limitations

Original release notes recorded a successful debug test/build workflow and a separate emulator-validation run. They did not establish physical-device playback, background/OEM behavior or duration accuracy. The Spotify API cannot recover history outside its available window or provide exact observed listening time.

## Install
