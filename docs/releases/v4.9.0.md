# Tempo 4.9.0

Tempo 4.9.0 is the first stable GitHub release of this fork. It uses package
`me.avinas.tempo`, Android version code 4819, and requires Android 8.0 or later.
The APK is built with the established fork signing key. An in-place upgrade
requires the installed APK to have the same signer.

## Changes

- Improved Daily Listening text contrast across appearance tones.
- Added Appearance Studio settings and saved looks to library backups.
- Made offline event staging incremental and added a recovery notice for unreadable records.
- Reduced repeated stats and gamification work and limited screen refreshes to visible destinations.
- Improved backup retention, restore staging, local reset, Spotify disconnect, and fork feedback routing.

## Installation and verification

Download the APK and SHA-256 checksum from this release. Export a backup before
reinstalling or changing signing identity. The artifact is an Android debug-variant
APK signed by the fork's configured key. GitHub distribution is separate from
the upstream Play listing.

Expected signing certificate SHA-256 is
`fa14beee34664d2c41bc5db00f630b564992da649fa66cb4e62c523915c95407`,
verified against the published 4.9.0-beta.1 APK.

The publication workflow runs unit tests, Android lint, APK assembly, Android
emulator tests, and browser companion checks against the release commit. Consult
the workflow run for their outcomes. Physical-device visual, accessibility,
playback and battery checks remain to be completed. The tracked service shutdown
and companion WebSocket interoperability issues remain open.
