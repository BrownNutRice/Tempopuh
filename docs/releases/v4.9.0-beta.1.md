# Tempo 4.9.0 Beta 1 — Reliability and import hardening

**17 November 2026 · Android 8.0+ · GitHub prerelease APK**

This is the first release using Tempo's SemVer scheme. The APK reports version `4.9.0-beta.1` and Android version code `4818`. Historical `4.8.16-fork.*` tags are retained unchanged.

## What changed

- Offline listening plays survive retry/pruning failures; retries are bounded and no longer sleep once per queued event.
- Spotify credentials fail closed when encrypted storage is unavailable. Migration snapshots verify copied database files, and analytics writes use atomic replacement.
- Browser extension controls reject unsigned, malformed, invalidly signed and replayed messages. The WebSocket handshake no longer transmits the shared token; pairing requires a signed acknowledgement. HTTP sync remains available.
- Browser host access no longer includes the global all-sites grant.
- Backup restore enforces decompressed-size and row limits. Spotify history is parsed into disk staging and replayed in bounded chunks. Musicolet database members are decrypted to cache files rather than duplicated in heap.
- Home distinguishes plays from unique tracks, refreshes at local date/time-zone boundaries, and explains session-start day attribution. Decorative animations respect reduced-motion settings.
- Manual beta validation now includes the browser extension typecheck and smoke checks.

## Validation

The release workflow publishes only after unit tests, Android lint, APK assembly, Android emulator tests, extension typecheck and extension smoke checks pass. Extension typecheck and smoke checks passed locally for this source. The local Gradle wrapper could not download Gradle 9.4.1 because this environment has no network route; the Android release gates must pass in the GitHub workflow before publication.

## Install and upgrade

**Export a backup of your listening data before upgrading.** Package ID is `me.avinas.tempo`. The APK is debug signed, not a Play Store build. In-place upgrades require the same signing certificate as your installed APK; if the signer differs, export data before uninstalling.

## Beta checks still needed on physical devices

- Check Light/System contrast, RTL, large text, TalkBack, popups, permission screens and 320dp layouts.
- Verify background playback capture, Now Playing artwork fallback, insets and lifecycle after screen-off/reboot.
- Check the new signed WebSocket handshake against the paired device implementation; the peer server is not part of this repository, so real-time WebSocket interoperability is not yet confirmed. HTTP sync continues to work independently.
- Measure battery and rendering performance before enabling heavier blur/refraction effects.

Report issues with device model, Android version and the steps needed to reproduce them.
