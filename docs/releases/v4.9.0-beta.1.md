Published 17 November 2026 · Version `4.9.0-beta.1` · Android code `4818` · Source `289fcd0f866b80495eed67bae98b74dbb1d7f32a`

## Highlights

- Durable pending-play recovery and retry scheduling improvements.
- Spotify credential storage fails closed when encrypted storage is unavailable.
- Signed browser WebSocket handshake/control validation and narrower host access.
- Bounded backup restore inputs and disk-staged Spotify/Musicolet imports.
- More explicit play-count and date-boundary behavior on Home.

## Install and known limitations

This is a prerelease **debug APK**, not an upstream Play build. Package `me.avinas.tempo`; Android 8.0+. Export a backup before upgrading or reinstalling. In-place updates require matching signing certificates.

Light/System contrast, large text, accessibility, background tracking, companion peer interoperability and performance still require device validation. The repository includes the phone HTTP service; the real-time WebSocket peer implementation/interoperability is not established by extension checks alone.

The [current audit indexes](https://github.com/matchalattewithbanana/Tempo/blob/main/docs/README.md#current-audit-and-proposal-indexes) list additional issues discovered after publication. Documentation maintenance and those proposed fixes are not included in this APK.
